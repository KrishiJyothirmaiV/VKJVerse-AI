# 💜 VKJVerse AI

**Your Universe of Stories ♡**

VKJVerse AI is an AI-powered movie and drama discovery application built using Python, Streamlit, TMDB API, and Google Gemini.

## Features

- 🔥 Trending movies and dramas
- 🔎 Movie and drama search
- 🌏 Entertainment discovery by country
- 📅 Episode Radar
- 🤖 Personalized recommendations
- 💬 Gemini AI Drama Assistant
- ❤️ Personal watchlist

## Technologies

Python, Streamlit, TMDB API, Google Gemini API, SQLite, and Requests.

## Getting Started

1. Clone this repository.
2. Install dependencies using `py -m pip install -r requirements.txt`.
3. Create a `.env` file using `.env.example` as a template.
4. Add your TMDB and Gemini API credentials to `.env`.
5. Start the application using `py -m streamlit run app.py`.
